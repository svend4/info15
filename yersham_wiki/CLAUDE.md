# Wiki Rules — @yersham Knowledge Base

## Назначение этой wiki

База знаний по YouTube-каналу @yersham (UCXu7rUYYfUmbe6jBS0bSeMQ).
Построена по принципам Karpathy LLM Knowledge Bases (апрель 2026).

## Структура файлов

```
raw/        — исходные данные (названия видео, ссылки) — не редактировать
wiki/       — структурированные статьи (этот каталог)
CLAUDE.md   — правила для агента
```

## Правила обновления

1. Каждая статья начинается с блока `> Связи: [[file]] [[file]]`
2. Ссылки между статьями: `[[имя-файла-без-расширения]]`
3. Видео обозначаются: `youtu.be/ID`
4. Нереализованные идеи помечаются: `⚠️`
5. Важность видео: звёзды `★★★★★`
6. Новые темы добавлять в `11-frontier-unrealized.md`
7. При добавлении новых персон — обновлять `12-key-figures.md`

## Формат записи видео

```
| Название видео | youtu.be/ID | ★★★★★ |
```
