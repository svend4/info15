> Самый важный раздел. Темы, которые канал поднял в 2025–2026,

## Уровень 1: Фундаментальная наука (нет консенсуса)

### 1.1 Сознание и интроспекция LLM
**Что**: возникающая интроспективная осознанность в больших языковых моделях.
**Видео**: youtu.be/7x8DQ4zDkSY, youtu.be/l7ahIl2cZ0U, youtu.be/nvSPezPkCzU
**Почему не реализовано**: нет методологии, нет консенсуса, тема табуирована в корпорациях.
**Потенциал**: меняет этику ИИ, право, философию разума.

### 1.2 Когнитивная атрофия от ИИ
**Что**: систематические изменения в человеческом мышлении при постоянном использовании ИИ.
**Видео**: youtu.be/AVPQWfBlVso
**Почему не реализовано**: нет лонгитюдных исследований, нейронаука отстаёт на 10 лет.
**Потенциал**: основа для политики образования, медицины, труда.

### 1.3 World Models (Мировые модели)
**Что**: модели ИИ, понимающие физику, причинность, время — не просто текст.
**Видео**: youtu.be/Kci_TZzd9IQ
**Почему не реализовано**: есть в исследованиях (Yann LeCun), нет в продакшне.
**Потенциал**: следующий уровень после LLM, основа для роботики и реального AGI.

## Уровень 2: Архитектурные инновации (есть прототипы, нет масштаба)

### 2.1 Байтовые модели без токенизации
**Что**: ИИ, читающий сырые байты вместо токенов. Архитектура xLSTM/Bolmo.
**Видео**: youtu.be/awq2PTsI0k8 ("Bolmo 1B: байтовые модели ИИ с XLSTM")
**Почему важно**: токенизация — искусственное ограничение, создающее "слепые пятна".
Байтовые модели лучше понимают код, языки с нестандартными символами, ДНК-последовательности.
**Статус**: исследовательские прототипы, нет продакшн-систем.

### 2.2 Нейропластичность в ИИ (RL2F)
**Что**: встроенная способность модели перестраивать веса в процессе работы.
**Видео**: youtu.be/hQVcb6S-pVU ("RL2F: How to Build Plasticity into AI for Self-Learning")
**Почему важно**: сейчас веса заморожены после обучения. Пластичность = непрерывное обучение.
**Статус**: концепция, несколько академических работ, нет реализации в масштабе.

### 2.3 Иерархические Модели Мышления
**Что**: архитектура, имитирующая двойную систему Канемана (быстрое + медленное мышление).
**Видео**: youtu.be/QtMjMqu_mt0
**Почему важно**: нынешние LLM — только "система 1" (быстрая, интуитивная).
**Статус**: теоретически описано, нет полной реализации.

### 2.4 Рекурсивное самоулучшение
**Что**: ИИ, улучшающий сам себя → экспоненциальный рост возможностей.
**Видео**: youtu.be/JCI_Ipa1AG8 ("Заря рекурсивного самоулучшения")
**Почему важно**: если реализуется — это точка невозврата в истории ИИ.
**Статус**: теоретически возможно, нет безопасной реализации.

### 2.5 Устойчивое решение катастрофического забывания
**Что**: модель, которая учится новому, не забывая старое.
**Видео**: youtu.be/TY0GI1s8Ra4 ("Как устранить катастрофическое забывание через GDIO")
**Почему важно**: без этого невозможно непрерывное обучение агентов.
**Статус**: GDIO — новый метод, не проверен в промышленных масштабах.

## Уровень 3: Методологии (сформулированы, не приняты)

### 3.1 Context Engineering как стандарт
**Что**: системное управление информационным потоком в ИИ-системах.
**Видео**: серия 10+ видео — см. [[04-context-engineering]]
**Почему не принято**: большинство разработчиков делает "промпты", не думает об архитектуре.
**Что нужно**: стандарт, фреймворк, инструменты, образование.

### 3.2 Spec-Driven Development (SDD)
**Что**: разработка ПО через спецификации, которые ИИ превращает в код.
**Видео**: серия 7 видео — см. [[05-spec-driven-dev]]
**Первая реализация**: Amazon Kiro (2025) — IDE на принципах SDD.
**Статус**: есть инструмент, нет массового принятия. 99% разработчиков делают vibe coding.

### 3.3 Domain Memory для агентов
**Что**: агент с персистентной доменной памятью — знает историю, контекст, предпочтения.
**Видео**: youtu.be/g6F9d41s96k
**Почему не реализовано**: технически сложно, нет стандарта, проблема приватности.

### 3.4 Agent Swarms для науки
**Что**: сотни ИИ-агентов, автономно проводящих научные эксперименты параллельно.
**Видео**: youtu.be/KGtrvhSFOsE ("AI swarms of researchers")
**Потенциал**: ускорение науки в тысячи раз.
**Статус**: единичные демонстрации, нет масштабной инфраструктуры.

## Уровень 4: Общество и экономика (самое нереализованное)

### 4.1 Post-AGI экономическая политика
**Что**: что делать с людьми, чьи профессии исчезли из-за ИИ.
**Видео**: youtu.be/TkBY57v1UQw, youtu.be/G8AuuUrwOVA
**Статус**: ни одно правительство мира не имеет реального плана.
ЕС, США, ООН — только декларации, нет операционных политик.

### 4.2 Приватизация высокоуровневого интеллекта
**Что**: кто контролирует доступ к самым мощным моделям?
**Видео**: youtu.be/C8HxOELtEQw ("Claude Mythos: приватизация высокоуровневого интеллекта")
**Вопрос**: AGI в руках 3–5 корпораций — это нормально?
**Статус**: нет международного регулирования, нет консенсуса.

### 4.3 Гелиевый кризис как ограничение ИИ
**Что**: нехватка гелия (охлаждение чипов, квантовые компьютеры) тормозит ИИ-инфраструктуру.
**Видео**: youtu.be/-u92D1JbpUE ("Гелиевый кризис: узкое место в глобальных поставках для AI")
**Статус**: реальная угроза, нет глобальной программы решения.
