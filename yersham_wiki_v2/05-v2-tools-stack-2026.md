# 05. Практический стек инструментов 2026

## Слои стека

1. **Модельный слой**: frontier + open-source модели по задаче.
2. **Оркестрация**: сценарии агентов, маршрутизация задач, tool-calling.
3. **Память/знания**: локальная wiki, заметки, индекс документов, векторный поиск.
4. **Проверка**: evals, тесты, политики качества.
5. **Публикация**: каналы доставки (документы, код, дашборды, контент).

## Принцип выбора инструментов

- Сначала задача и SLA, потом инструмент.
- Чем выше риск, тем выше требование к проверяемости.
- Избегать lock-in: хранить критичные знания в переносимых форматах.
